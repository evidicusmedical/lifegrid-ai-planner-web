# Task sorting contract — v0.5.22

Smart priority remains the default and the chosen mode persists as the optional `lifegrid_task_sort` UI preference. The eight modes and exact one-line explanations are exported from the pure `taskWorkflow` helper. Status rank is To do (`todo`), In progress (`in-progress`), Blocked (`blocked`), Done (`done`); unknown legacy values sort after canonical values. Priority is Urgent, High, Medium, Low, then missing/unknown. Names use a case-insensitive, locale- and numeric-aware collator with ID tie-breaks. Tag/Category resolves the visible Category label, leaves unassigned/unknown labels last, then uses task name and ID. Both due-date modes leave undated Tasks last. Smart priority uses date-only arithmetic and keeps urgent undated and blocked undated Tasks actionable without putting ordinary low-priority undated work ahead of near-due work.
