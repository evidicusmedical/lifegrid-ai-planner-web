# Recurring all-day edit contract — v0.5.22

LifeGrid recurrence is currently a group of materialized sibling records linked by `recurringGroupId`, not a generated master/occurrence rule engine; therefore the supported UI scopes remain individual save and group delete. The pure range normalizer replaces the prior occurrence date and preserves the original inclusive day duration using date-only UTC arithmetic as a timezone-independent representation of YYYY-MM-DD values. One-day, missing-end, and stale-end inputs normalize to `endDate = date`; valid multiday input preserves duration. Notes-only field-diff detection is supplied for future scope-capable editors. No unsupported This and following / Entire series structural mutation UI is invented in this compatibility release.
