# LifeGrid v0.5.23

LifeGrid v0.5.23 makes every desktop Grid Event previewable, establishes deterministic timed-first ordering and canonical single-record multi-day Events, adds optional direct Event Projects, simplifies editors to All day/Timed, adds Task status filtering, defaults AI export to complete context, hardens AI relationships, and polishes export and Settings management.

Compatibility is additive: AI interchange remains v4, backup remains schema 7, legacy approximate/unknown and relationship fields remain readable, and no load-time user-data rewrite occurs.
