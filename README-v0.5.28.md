# LifeGrid v0.5.28 — Smart publication readability

LifeGrid image export remains a simple choice of **what** to share; a deterministic, offline publication planner chooses **how** to present it. One relaxed, standard, or dense text profile is selected from the filtered date/event density and shared by DOM and Canvas2D output. Dates are structural month/day labels that never ellipsize, event titles use bounded multiline fitting, category legends wrap, and capture dimensions follow rendered content.

The v0.5.28 renderer strategy, range semantics, category/project filtering, all-event policy, current theme, AI Interchange v5, and backup schema v7 are unchanged. AI authoring now receives soft concise/scannable title guidance, not validation.

The final geometry contract shares the Grid's 32 px day column and 110 px month columns with the planner. Month publications use an explicit border-box and 24 px exterior margins, allowing headers and legends to wrap vertically without widening the PNG.
