# LifeGrid v0.5.25 — reliable targeted Grid images

LifeGrid v0.5.25 hardens portable PNG schedules for Next 7, Next 14, Next 30, and Custom ranges without redesigning Grid export. The capture source now renders at normal coordinates, independently of annual Grid staging and interactive scrolling. Relative presets start today, short Custom ranges can cross a year boundary, private (`showInExport: false`) Events are consistently excluded, and meaningful empty schedules can be exported.

The release adds real browser PNG and download qualification. Remaining release acceptance is manual iPhone Safari Share/long-press and layout verification. AI interchange version 4 and backup schema version 7 are unchanged.
